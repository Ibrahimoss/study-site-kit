Sample spaces and events
Introduction to Probability - Unit 1
An experiment is any process with an uncertain result
The sample space S is the set of all possible outcomes
Example: one die gives S = {1, 2, 3, 4, 5, 6}
An event is a subset of S, e.g. A = "even" = {2, 4, 6}
A ∪ B: A or B happens;  A ∩ B: both happen
A' (complement): A does not happen
Disjoint events: A ∩ B is empty (cannot happen together)

=== u1 page 3 ===
The axioms of probability
Introduction to Probability - Unit 1
Axiom 1: P(A) ≥ 0 for every event A
Axiom 2: P(S) = 1
Axiom 3: if A and B are disjoint, P(A ∪ B) = P(A) + P(B)
Consequences:
0 ≤ P(A) ≤ 1
P(empty set) = 0
If A ⊆ B then P(A) ≤ P(B)

=== u1 page 4 ===
Two rules you will use every time
Introduction to Probability - Unit 1
Complement rule
P(A') = 1 - P(A)
Addition rule (any two events)
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
Subtract the overlap, otherwise it is counted twice.
For disjoint events P(A ∩ B) = 0, so the rule becomes Axiom 3.
